Project — GrowthOS

Building a Personal OS

Visit Live Site
⚡
The Problem
Productivity apps do one thing. I needed them all.
Habit trackers don't help you set goals. Goal apps don't track skills. Journal apps don't show your progress over time. I wanted a single system that combined everything — and made it feel like leveling up in a game rather than checking boxes on a list.
Step 01
Designing the XP System
The gamification layer was the core idea, so it got designed first. I mapped out how XP would be earned, how levels would scale, and how skills would branch — before writing a single line of UI code. The logic had to feel fair and rewarding, not arbitrary.
Game DesignLogic FirstState Architecture
Step 02
Multi-Section Navigation
GrowthOS has 12+ sections (Overview, Habits, Journal, Trades, Analytics, Identity, etc.). I built the routing system in Next.js with a persistent sidebar — each section is its own page with shared state. The sidebar collapses on mobile without breaking layout.
Next.jsReact RouterShared State
Step 03
Firebase for Persistence
Without persistent data, the XP system is pointless. I integrated Firebase for real-time database updates — streak counters, habit completion, XP totals, and reflection journals all persist across sessions. Auth lets the user have their own profile.
FirebaseRealtime DBAuth
Step 04
Identity & Philosophy Layer
The Identity and Rules sections were the most unique part of GrowthOS. A user defines who they want to become, sets their personal code of conduct, and the system surfaces these daily. It's the part that makes GrowthOS feel like a personal OS rather than just a tracker.
UX DesignPhilosophy SystemPersonal Branding
02
Project — Trove

Building an AI Reading Platform

Visit Live Site
📚
The Problem
People read a lot and retain almost nothing.
I noticed that saving content — highlights, links, notes — didn't mean understanding it. The insight extraction step was always missing. Most apps are just storage. Trove was designed to force the user to think: What did I learn? How can I use this? The AI layer surfaces that for you automatically.
Step 01
The Vault Architecture
I designed the knowledge structure first — categories, subcategories, tags, value scores, and insight fields. This data model determines everything else. Getting it right before touching the UI meant the React components just had to display what the structure already knew.
Data ModellingArchitectureSchema Design
Step 02
AI Insight Extraction
The AI layer was the hardest and most important feature. I had to prompt the model to surface genuine insights — not summaries. The prompt engineering work was significant: getting the model to produce actionable insights rather than just restating the book's content took multiple iterations.
AI APIPrompt EngineeringKnowledge Extraction
Step 03
The Circle — Social Layer
The social component (The Circle) was built last — after the core vault was solid. Private reading clubs, discussion threads, and member discovery required careful auth scoping to ensure club privacy. Naira payment integration via Paystack unlocks premium Circle access.
Auth ScopingPaystack ₦Social UX
Step 04
Book Ingestion Pipeline
Supporting PDF, EPUB, and TXT required building a file parsing pipeline that normalizes different formats into the same internal structure. The parser strips formatting and extracts clean text that the AI layer can work with — regardless of what format the user uploads.
File ParsingPDF/EPUB/TXTPipeline Design
03
Project — This Portfolio

Building the Portfolio Site

01
Design Direction
Dark cinematic aesthetic — game UI crossed with developer brand. Every color, spacing, and motion decision was intentional. No templates, no frameworks.
02
Canvas Particle System
120 particles with velocity vectors and proximity line connections — pure HTML5 Canvas API and requestAnimationFrame. No libraries.
03
Scroll Animations
IntersectionObserver triggers staggered fade-up reveals on every section. Skill bars animate in on viewport entry. Zero GSAP.
04
3D Card Tilt
Mouse position mapped to CSS perspective() + rotateX/Y transforms in real time. Creates a physical depth illusion without any 3D library.
🖥️
Tech Stack — Portfolio Site
Pure HTML · CSS · Vanilla JavaScript · Zero frameworks
The whole site is hand-crafted. No Bootstrap, no Tailwind, no React. Every animation, every glow, every particle is something I understand and control at the source code level. Multi-page architecture with shared design language across 5 pages. Deployed to Vercel.
