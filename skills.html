How I Learn
📖
Self-Study Before Lectures
I study course material before the lecture — so when I'm in class, I'm revising, not learning from scratch. This compounds: I understand more, retain more, and ask better questions.
🛠️
Build Real Projects Early
Theory only sticks when it touches reality. Every major concept I learn becomes a project I build. OOP became a ride-share system. Data viz became dashboard modules.
🧠
Spaced Repetition
I use Anki and structured review cycles to retain what I learn long-term. It's not about cramming — it's about building durable knowledge that shows up on exams and in code.
🔁
Learn by Shipping
The best learning feedback loop is deploying something real. Live URL = the feature works. 404 = go back and fix it. Production pressure teaches what tutorials never can.
